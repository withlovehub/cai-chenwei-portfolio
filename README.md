# 蔡辰玮 CAI CHENWEI — Personal Portfolio

基于 React + Vite 的个人博客 / 作品集首版，定位为高级、克制、偏编辑部式的科技视觉风格。

## 本地运行

```bash
npm install
npm run dev
```

浏览器打开 Vite 输出的本地地址即可预览。

## 构建生产版本

```bash
npm run build
npm run preview
```

## 修改个人内容

- `src/data.js`：姓名、简介、联系方式、经历、项目与个人优势。
- `src/App.jsx`：页面结构、视频背景地址与交互逻辑。
- `src/styles.css`：颜色、字体、排版、动效与响应式样式。
- `index.html`：页面标题、搜索描述与浏览器图标。

当前个人信息已根据简历更新；抽象头像、项目图片和背景视频仍是演示素材，上线前可替换为你的真实照片与作品图。
